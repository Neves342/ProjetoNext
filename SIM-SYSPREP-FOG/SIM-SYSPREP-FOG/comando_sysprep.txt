1 - Preparar Windows com todos os programas;
2 - Copiar arquivo "SetupComplete.cmd" para o diretório "C:\Windows\Setup\Scripts\" (criar diretório caso não exista);
3 - Copiar o arquivo resposta "arquivo_resposta.xml" para o diretório "C:\Windows\System32\Sysprep";
4 - Instalar FOGService;
5 - Colocar FOG na exceção do antivirus e do firewall
netsh advfirewall firewall add rule name="Fog Client" dir=in action=allow program="C:\Program Files (x86)\FOG\FOGService.exe" enable=yes
netsh advfirewall firewall add rule name="FOGShutdownGUI" dir=in action=allow program="C:\Program Files (x86)\FOG\FOGShutdownGUI.exe" enable=yes
netsh advfirewall firewall add rule name="FOGTray" dir=in action=allow program="C:\Program Files (x86)\FOG\FOGTray.exe" enable=yes
netsh advfirewall firewall add rule name="FOGUpdateWaiter" dir=in action=allow program="C:\Program Files (x86)\FOG\FOGUpdateWaiter.exe" enable=yes
netsh advfirewall firewall add rule name="FOGUserService" dir=in action=allow program="C:\Program Files (x86)\FOG\FOGUserService.exe" enable=yes

6 - Desabilitar o FOGService na inicialização (caso não seja desabilitado irá corromper a imagem do windows);
6.1 - Caso seja em unidades diferentes, editar o arquivo C:\Program Files (x86)\FOG\settings.json e mudar o IP para o correto;
7 - Abrir o CMD com Administrador, entrar no diretório "cd C:\Windows\System32\Sysprep";
8 - Executar p comando: sysprep /generalize /oobe /shutdown /unattend:Win_Pro_11_22H2.xml
